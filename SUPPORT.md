# Support

Use GitHub Issues for reproducible bugs, feature requests, and documentation
gaps.

For questions, include:

- Your operating system.
- The Nostr-Q version or commit.
- The command you ran.
- The relay URL type you are using, such as local Docker relay, private relay,
  or public relay.
- Relevant logs with private keys and secrets removed.

Security reports should follow [SECURITY.md](SECURITY.md), not public issues.
