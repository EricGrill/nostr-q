# Code of Conduct

This project expects respectful, constructive participation.

## Expected Behavior

- Be direct and technical without personal attacks.
- Assume good intent, but correct problems clearly.
- Keep discussions focused on the work.
- Respect maintainers' decisions about scope, safety, and release timing.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing private information without consent.
- Repeated off-topic comments after being asked to stop.
- Security disclosure in public before maintainers have had a reasonable chance
  to respond.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; block users; or
reject contributions that violate this code.
